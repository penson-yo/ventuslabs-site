Clara

The Problem

Great ideas don't wait for
a good filing system.

ADHD brains generate constant ideas, observations, and tasks — at the worst possible moments. The cost of capturing them is too high. The cost of losing them is higher. Most capture tools demand too much: open the app, find the right note, type it out, file it properly. By then, the thought is gone.

Too much friction

Every extra tap is a chance to lose the thought or abandon the habit entirely.

No one wants to sort

Even when you capture something, deciding where it goes is its own executive function tax.

Tools that don't stick

The perfect note-taking system only works if you actually use it. Most don't survive contact with a real day.

How It Works

Speak. Clara handles the rest.

1

Hold and speak

Tap once and say anything — a task, an idea, a reminder, an observation. Clara listens with Whisper-grade transcription. No typing required.

2

AI routes it intelligently

Claude reads the content and decides where it belongs — is this a task to do, a calendar event, or a piece of knowledge to keep? It routes it accordingly with no input from you.

3

It lands in the right place

Clara writes clean markdown directly to iCloud Drive — organized, Obsidian-compatible, and yours. No proprietary database. No lock-in. Just files.

The System

Three buckets. Everything fits.

Clara uses the ACE framework — a minimal, universal structure that every thought can land in.

A

Atlas

Knowledge & Ideas

Concepts, references, things you want to remember. The permanent layer of what you know. "What is this about?"

C

Calendar

Time-Anchored Moments

Daily notes, events, and anything tied to a date or time. The temporal layer of what happened. "When did this happen?"

E

Efforts

Projects & Tasks

Active work, checklists, and in-progress projects. The action layer of what you're doing. "What am I working on?"

Under the Hood

Built with best-in-class AI

Whisper API

OpenAI's speech-to-text for fast, accurate transcription in any environment.

Claude API

Anthropic's Claude handles all routing decisions — deciding where each thought belongs.

Native iOS

Built in Swift/SwiftUI for the snappiest possible experience. No web wrappers.

iCloud Storage

Plain markdown files synced via iCloud Drive. Open in Obsidian or any text editor.
